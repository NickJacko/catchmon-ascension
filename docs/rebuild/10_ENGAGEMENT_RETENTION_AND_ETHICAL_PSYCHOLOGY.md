# 10 — Engagement, Retention & Ethical Psychology

# 1. Objective

Catchmon Ascension should be **extremely compelling to return to** while avoiding deliberate behavioral harm.

The goal is stronger retention through:
- clearer progress,
- mastery,
- collection attachment,
- strategic experimentation,
- novelty,
- satisfying anticipation.

Not through punitive absence, deceptive odds or gambling-like spending pressure.

# 2. Competence

Players repeatedly feel:
- “I understand why I improved.”
- “My build decision mattered.”
- “I can solve that boss.”

Boss feedback, Build Fit and deterministic progress reinforce competence.

# 3. Autonomy

Players choose:
- Battle Path,
- Relics,
- support Catchmons,
- skills,
- region/activity targets.

Avoid false choices where one option is mathematically mandatory.

# 4. Relatedness

Attachment comes from:
- Catchmon collection,
- evolution,
- Bond,
- optional guild cooperation,
- sharing builds/achievements.

# 5. Curiosity Loop

Forge uncertainty asks:
- which slot?
- which affixes?
- good for my build?
- new effect?

The result is always truthful. No fake near miss.

# 6. Completion Tension

Visible near-completion is encouraged:
- 8/10 Bond,
- 92/100 Insight,
- 4/5 discoveries,
- boss at 7% remaining.

The player should know exactly what the meter means.

# 7. Multi-Horizon Goal Stack

Always provide:

Immediate — Forge/boss/item choice.  
Short — skill/Bond/slot upgrade.  
Session — boss/evolution/world milestone.  
Long — build, region, evolution line.  
Collection — roster/element/rare species.

Depth comes from nested goals, not icon count.

# 8. Novelty Cadence

Stagger system unlocks by progress.

Principles:
- one system at a time,
- immediate use,
- time to understand,
- no purchase popup attached to unlock.

Early novelty must transition into strategy rather than endless feature stacking.

# 9. Avoid Midgame Collapse

Countermeasures to “fun first two weeks, wall afterward”:

1. Forge safety meter.
2. Build optimization matters increasingly.
3. Boss mechanics create new problems.
4. support roster expands.
5. Skill Mastery changes behavior.
6. regional modifiers change good builds.
7. deterministic Research offers guaranteed progress.
8. new worlds add decisions, not only larger numbers.

# 10. Automation as Retention

Repetition that is fun 10 times becomes a chore at 1,000.

Manual → filters → batch → smart auto.

Keep strategic choices, automate execution.

# 11. Streaks

Streaks celebrate continuity but do not punish absence.

Good:
- cosmetic streak,
- small bonus.

Bad:
- erased accumulated rewards,
- permanently missed power,
- escalating purchase pressure.

# 12. Daily Design

Essential daily loop target: 5–15 minutes.

Optional longer play:
- stage pushing,
- build testing,
- collection,
- events.

No mandatory 45-minute checklist.

# 13. Variable Rewards

Variable rewards may exist when earned through gameplay.

Safety rules:
- transparent odds where material,
- visible protection/pity,
- no paid random power loop,
- recycle failures still progress,
- no unlimited real-money repeat purchase.

# 14. Social Pressure

Avoid:
- mandatory narrow attendance windows,
- punitive guild systems,
- whale-dominated rankings as main progression.

Prefer asynchronous cooperation and optional fair competition.

# 15. Notifications

Notify useful state changes only:
- expedition finished,
- optional offline-cap reminder,
- social milestone.

No guilt messages.

# 16. Metrics

Measure:
- D1/D7/D30 retention,
- voluntary return rate,
- build diversity,
- system comprehension,
- boss retry-to-success ratio,
- churn at walls,
- fairness perception,
- natural stopping-point usage.

Do not optimize only for maximum session length.

# 17. North Star

> Players return because they have a plan to try, a Catchmon to evolve, a build to complete and a world to beat.
