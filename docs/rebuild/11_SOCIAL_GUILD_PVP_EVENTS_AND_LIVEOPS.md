# 11 — Social, Guild, PvP, Events & LiveOps

# 1. Scope

Social systems are long-tail retention, not vertical-slice prerequisites.

Build the single-player loop first.

# 2. Guild Concept

Working name: **Expedition Lodge**.

Purpose:
- cooperative goals,
- build discussion,
- optional social identity,
- shared expeditions/events.

Do not copy “Family” terminology or competitor event structures.

# 3. Guild Actions

Potential systems:
- contribute routine resources to a shared project,
- send support assistance,
- cooperative weekly boss,
- shared region exploration,
- guild research choice.

No mandatory hourly check-in.

# 4. Timer Help

If timer help exists:
- optional,
- capped,
- aggregated automatically where possible,
- no spam-clicking dozens of requests.

# 5. PvP

PvP is optional.

Preferred format:
- asynchronous build snapshots,
- short deterministic/simulated battles,
- leagues/brackets,
- seasonal soft resets.

PvE progression never requires high PvP rank.

# 6. Competitive Fairness

Tools may include:
- power brackets,
- normalized challenge modes,
- limited-roster drafts,
- build-rule seasons.

Avoid raw spending as the main determinant of rank.

# 7. Event Templates

Events remix existing systems rather than creating unrelated mini-games.

## World Surge
A region gains modifiers and bonus goals.

## Forge Challenge
Score through intelligent Forge/recycle decisions, not paid pull volume.

## Bond Expedition
Use underplayed Catchmons for cooperative targets.

## Boss Circuit
Rotating build-check bosses.

## Collection Trail
Discovery and evolution objectives.

# 8. LiveOps Rules

Do:
- reuse core mechanics,
- add decisions,
- support catch-up,
- make rewards understandable.

Do not:
- create a new currency for every event,
- require 24/7 availability,
- run spending leaderboards,
- sell randomized event power.

# 9. Server Model

Do not architect around disposable new-server rush cycles.

Prefer:
- persistent accounts,
- matchmaking cohorts,
- optional seasons.

This avoids dead-server/restart pressure.

# 10. Seasonal Content

Seasons may introduce:
- modifiers,
- cosmetics,
- rankings,
- temporary challenge rules.

Permanent collection/progression remains. No forced wipe.

# 11. Monetization Boundary

If monetization arrives later, prefer:
- cosmetics,
- Forge visual themes,
- profile decoration,
- convenience that does not dominate competition,
- optional content packs.

Avoid:
- paid random Relics,
- paid Catchmon duplicate ladders,
- permanent exclusive PvP power,
- opaque currency bundles.

# 12. Exit Gate

Social/live systems ship only after:
- core loop works without them,
- guild participation is asynchronous-friendly,
- competitive rewards do not gate PvE,
- events are original rather than reskinned competitor events.
