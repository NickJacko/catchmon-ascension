# 07 — Meta Progression & Account Systems

# 1. Purpose

Meta systems create long-term goals without becoming a dashboard of unrelated power bars.

Every system needs a distinct purpose.

# 2. Core Meta Systems

Long-term candidates:
1. Journey Rank
2. Rift Forge Level
3. Catchmon Bond/Evolution
4. Skill Mastery
5. Relic Codex
6. Research Constellation

Only the first four are mandatory in the initial slice.

# 3. Journey Rank

Represents broad account progression.

Sources:
- stages,
- bosses,
- region milestones,
- collection milestones.

Uses:
- system unlocks,
- loadout slots,
- region access,
- advanced feature gates.

Journey Rank is not a spendable currency.

# 4. Forge Level

Defined in Doc 04. It is the long-term progression of the central reward engine.

# 5. Research Constellation

A compact permanent choice grid.

Potential branches:
- Forge
- Combat
- Bond
- Expedition
- Offline Efficiency

Target final scale: roughly 20–40 meaningful nodes, not a 200-node filler tree.

# 6. Relic Codex

Tracks discovered Relic types/effects.

Rewards:
- collection completion,
- small deterministic bonuses,
- cosmetics/titles.

It is not a second inventory.

# 7. Unlock Philosophy

Stagger systems by **player milestone**, not server age.

Example sequence:
- Forge: immediate
- Bond Support: first boss
- Battle Path: first region midpoint
- Skills: first elite
- Expeditions: first region completion
- Research: second region
- Guild/social: later

A returning player should not have eleven systems dumped onto them instantly.

# 8. New-System Contract

Every system unlock gives:
1. one-sentence fantasy,
2. one meaningful action,
3. one visible benefit,
4. one future goal,
5. no purchase popup.

# 9. Progression Walls

When stalled, surface several options:
- Forge improvements,
- Relic optimization,
- Skill mastery,
- support change,
- Bond/evolution,
- Research,
- offline accumulation.

A wall may encourage strategy or a short wait. It must not make payment the only practical answer.

# 10. Catch-Up

Returning players get:
- offline rewards,
- deterministic accumulated progress,
- concise “what changed / what next” summary.

# 11. No Prestige Reset

No global reset/prestige loop.

Growth extends forward through regions, branches, Forge tiers, collection and optional seasons.

# 12. Exit Gate

- unlocks are milestone-driven,
- one clear next system is visible,
- deterministic investment can overcome bad Forge luck,
- no two meta systems exist solely to increase the same number.
