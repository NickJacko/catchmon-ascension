# 09 — Economy, Currencies & Reward Pacing

# 1. Goal

The economy must be understandable without a spreadsheet while still supporting long-term progression.

Avoid one currency per system.

# 2. Core Currencies

## Coins
Universal routine upgrade currency.

Sources:
- battles,
- recycling,
- offline rewards,
- expeditions.

Sinks:
- Forge Level,
- skill upgrades,
- selected deterministic systems.

## Echo Charges
Forge activations earned through play.

Sink:
- Rift Forge only.

## Essence
Universal advanced growth material.

Sources:
- bosses,
- collection milestones,
- rare expeditions.

Sinks:
- evolution,
- skill mastery,
- advanced research.

## Guild Credits
Only if social systems ship.

# 3. Premium Currency

Not required for the initial product.

If monetization is later introduced:
- one premium currency,
- clear real-money equivalence,
- no randomized paid combat power,
- no currency chains designed to obscure price.

# 4. Reward Cadence

Target:

Every 10–30 sec:
- combat/Forge progress.

Every 2–5 min:
- meaningful upgrade/checkpoint.

Every 10–20 min:
- boss/world/build milestone.

Every session:
- one visible long-term meter advances.

Every return:
- useful offline progress.

# 5. Random vs Deterministic

Random:
- Relic slot/rarity/affixes,
- selected encounters,
- optional reward choices.

Deterministic:
- Forge Level,
- Journey Rank,
- Insight/protection,
- Bond,
- evolution,
- Skill Mastery,
- Research.

Randomness creates surprise; deterministic systems guarantee progress.

# 6. Anti-Wall Model

Bad Forge luck still produces:
- recycle value,
- Forge Insight,
- Coins,
- offline Charge accumulation,
- Bond/Research progress.

Expected time to an upgrade may grow, but never become undefined.

# 7. Inflation Control

Do not solve inflation with more currencies.

Use:
- new sinks,
- higher tiers,
- caps,
- sensible conversion.

# 8. Power Curve

Early: rapid visible growth.  
Mid: build quality matters.  
Late: collection, specialization and region optimization matter more than raw inflation.

# 9. Event Economy

Events primarily reuse core currencies.

One temporary event token is acceptable only when the event truly needs it.

No five-currency event stack or expiring paid currency.

# 10. Offline Economy

Use the last stable farm checkpoint.

Caps should be generous enough that work/sleep does not feel punitive.

# 11. Simulation

Before scale-up simulate:
- first hour,
- first day,
- first week,
- unlucky Forge streak,
- lucky streak,
- offline-heavy player,
- active optimizer.

Balance remains provisional until simulation + playtest.

# 12. Exit Gate

- core currencies are explainable,
- bad luck still advances deterministic progress,
- no system currency exists without unique purpose,
- no progression wall has spending as its only practical solution.
