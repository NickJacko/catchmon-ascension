# 05 — Battle Paths, Skills & Loadouts

# 1. Purpose

The early game is simple. The midgame becomes a build game.

The player should be able to answer:

> “What is my build trying to do?”

# 2. Battle Paths

## Breaker
Core verbs: attack quickly, chain hits, crit, overwhelm.

Primary stats:
Attack Speed, Combo, Crit, Crit Damage.

## Warden
Core verbs: absorb, guard, counter, outlast.

Primary stats:
Defense, Guard, Counter, Recovery.

## Weaver
Core verbs: cast, trigger elements, accelerate cooldowns, control tempo.

Primary stats:
Skill Power, Skill Haste, Elemental Power.

Paths can be switched with low friction outside combat. No irreversible beginner trap.

# 3. Advanced Branches

Working original branches:

Breaker:
- **Ravager** — crit/burst.
- **Chainrunner** — combo/attack-speed.

Warden:
- **Bulwark** — guard/sustain.
- **Reprisal** — counter/damage return.

Weaver:
- **Invoker** — elemental skill burst.
- **Chronist** — cooldown/tempo control.

Names can change before production branding.

# 4. Skill Loadout

Initial target:
- 4 Active Skills
- 1 Signature Skill
- 2 Passive Traits

Skills come from progression, world milestones, Catchmon mastery, bosses and deterministic research.

No baseline paid skill gacha.

# 5. Skill Progression

A skill may have:
- level,
- mastery,
- branch modifier.

Level = numeric growth.  
Mastery = behavior change.

Examples:
- projectile becomes multi-hit,
- shield enables counters,
- skill gains elemental interaction,
- cooldown converts into charges.

# 6. Species Identity

Each species line may contribute:
- Signature candidate,
- Bond Support behavior,
- evolution modifier.

Battle Path = strategic style.  
Species = creature identity.

Neither replaces the other.

# 7. Loadouts

Players can save named loadouts containing:
- Lead Catchmon,
- Bond Supports,
- Battle Path/specialization,
- Relic Matrix,
- skill configuration.

Use cases:
- farming,
- bosses,
- expedition challenges,
- PvP later.

# 8. Build Fit

Build Fit explains synergy:
- “Strong Crit concentration”
- “Low Combo support for Chainrunner”
- “Two effects require Guard but Guard is low”

Build Fit is advisory, not a hidden authority.

# 9. Respec

Players should experiment.

- early respec free,
- later switching low-friction,
- no expensive real-money class change,
- no permanent damage from a beginner choice.

# 10. Depth Guardrail

A new stat/system is justified only if it creates a decision.

Bad:
- five different +Attack trees.

Good:
- one system changes skill behavior,
- one changes Relic profile,
- one changes support composition.

# 11. Exit Gate

- Breaker/Warden/Weaver behave differently.
- same rarity item can be good for one Path and poor for another.
- Bond Supports affect Build Fit.
- skill/loadouts persist.
- respec works without restarting progression.
